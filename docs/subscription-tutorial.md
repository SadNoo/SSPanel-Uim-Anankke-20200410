# 客户端订阅使用教程

本教程说明如何在面板「客户端订阅」区域获取订阅，并导入到常用客户端。

![客户端订阅区域](images/subscription-panel.png)

> **重要提示**
>
> - 订阅链接包含你的账号凭证，**不要发给他人**，也不要贴到公开群组或论坛。
> - 如果订阅链接泄露，请在面板中重置订阅链接，旧链接会失效。
> - 所有客户端导入后都需要 **更新订阅** 才能拉取节点；节点有变动时也要重新更新。

---

## 一、怎么选客户端

| 你的设备 | 推荐客户端 | 使用面板里的哪个订阅 |
| --- | --- | --- |
| iPhone / iPad / Mac | sing-box（App Store） | sing-box |
| Android | sing-box（SFA）或 v2rayNG | sing-box / v2rayN / v2rayNG |
| Windows | v2rayN 或 Clash Verge Rev | v2rayN / v2rayNG 或 Clash |
| macOS / Linux 桌面 | Clash Verge Rev 或 sing-box | Clash / sing-box |

三种订阅都包含 **VMess + SS2022 + VLESS** 节点，区别只在于格式适配哪种客户端。**订阅类型必须和客户端对应**，例如 Clash 订阅不能导入 v2rayN。

---

## 二、sing-box

### 1. 在面板中选择配置

1. **配置版本**：在下拉框里选择与你客户端版本相符的配置。
   - 默认的「1.14 兼容版」适用于大多数用户。
   - 如果客户端较旧导入报错，请先把客户端升级到最新版。
2. **模式**：
   | 模式 | 说明 |
   | --- | --- |
   | 普通 | 默认配置，**不确定就选这个** |
   | QUIC | 使用 QUIC（基于 UDP）传输；若所在网络限制 UDP，可能连不上，此时换回「普通」 |
   | Tailscale | 在配置中加入 Tailscale 相关设置，仅在你需要 Tailscale 组网时使用 |
   | Tailscale + QUIC | 同时启用以上两项 |
3. 选好后下方会显示当前选择，例如「普通 · 保持当前默认配置」。

> 每次切换版本或模式后，订阅链接都会变化，需要**重新复制或重新导入**。

### 2. 导入客户端

**方式 A：一键导入（推荐）**

在已安装 sing-box 的设备上打开面板，点击 **「一键导入」**，浏览器会唤起 sing-box，确认添加即可。

**方式 B：复制订阅手动添加**

1. 点击 **「复制订阅」**。
2. 打开 sing-box → **Profiles（配置）** → **New Profile（新建）**。
3. Type 选择 **Remote（远程）**，名称随意填写，URL 粘贴刚才复制的链接。
4. 保存后回到 **Dashboard（仪表盘）**，选中该配置，点击启用。
5. 首次启用时系统会请求添加 VPN 配置，点击 **允许**。

## 三、v2rayN（Windows）/ v2rayNG（Android）

面板中的「v2rayN / v2rayNG」订阅是 **VMess + SS2022 + VLESS 共用链接**，两个客户端都可以使用。

### v2rayNG（Android）

**一键导入**：在手机上点击面板的 **「导入 v2rayNG」**，按提示确认后，进入 v2rayNG 右上角菜单 → **更新订阅**。

**手动添加**：

1. 点击 **「复制混合订阅」**。
2. 打开 v2rayNG → 左上角菜单 → **订阅分组设置** → 右上角 **＋**。
3. 备注随意填写，URL 粘贴订阅链接，保存。
4. 返回主界面 → 右上角 **⋮** → **更新订阅**。
5. 选择一个节点，点击右下角的 **V** 图标连接。

### v2rayN（Windows）

1. 点击 **「复制混合订阅」**。
2. 打开 v2rayN → **订阅分组** → **订阅分组设置** → **添加**。
3. 备注随意填写，地址粘贴订阅链接，确定。
4. 回到主界面 → **订阅分组** → **更新全部订阅（不通过代理）**。
5. 选中节点后按 **Enter** 设为活动服务器，在系统托盘将 **系统代理** 设为「自动配置系统代理」。

> 请使用较新版本的 v2rayN / v2rayNG，旧版本可能不支持 SS2022 或 VLESS 节点。

## 四、Clash

面板的 Clash 订阅包含 **SS2022 与 VLESS** 节点，**原版 Clash（已停更）不支持**，请使用 mihomo（Clash Meta）内核的客户端：

- Windows / macOS / Linux：**Clash Verge Rev**
- Android：**FlClash** 或 **Clash Meta for Android**

**一键导入**：点击面板中的 **「一键导入」**，浏览器会唤起 Clash 客户端，确认导入即可。

**手动添加（以 Clash Verge Rev 为例）**：

1. 点击 **「复制订阅」**。
2. 打开 Clash Verge Rev → **订阅**，在顶部输入框粘贴链接 → 点击 **导入**。
3. 点击导入后的订阅卡片使其生效。
4. 进入 **代理** 页选择节点，在 **设置** 中打开 **系统代理**（或 TUN 模式）。

## 五、常见问题

**Q：一键导入没反应？**
A：说明设备上没有安装对应客户端，或浏览器拦截了唤起。请先安装客户端，或改用「复制订阅」手动添加。

**Q：导入成功但没有节点 / 更新失败？**
A：
1. 确认账号未过期、流量未用完。
2. 确认订阅类型与客户端对应。
3. 更新订阅时选择「不通过代理」，或先关闭其他代理软件再更新。

**Q：有节点但连不上？**
A：
1. 检查设备时间是否准确（误差过大会导致 VMess 连接失败），开启自动同步时间。
2. sing-box 用户选了 QUIC 模式的，换回「普通」重试。
3. 换其他节点测试；仍不行请提交工单，并附上客户端名称、版本和报错截图。

**Q：订阅链接泄露了怎么办？**
A：在面板中重置订阅链接，然后在所有客户端中重新导入新链接。
